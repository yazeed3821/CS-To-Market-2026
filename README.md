# 9-Weeks Tech Career Sprint | CS-To-Market-2026

An intensive 9-week technical exploration journey undertaken prior to graduating with a Bachelor's in Computer Science. The objective is to deep-dive into core computer science domains, construct end-to-end practical deliverables for each, and identify the optimal career path.

## Project Goals
* **Hands-on work:** Build functional software artifacts instead of relying solely on theory.
* **Architecture & Clean Code:** Apply modern software engineering practices, version control standards, and documentation.
