# E-commerce Data Cleaning and Analysis

A practical data analysis project focusing on handling missing values and extracting business insights.

## Process
1. Data Generation Created a mock dataset with deliberate missing values (NaN) to simulate real-world messy data.
2. Data Cleaning 
   - Imputed missing 'age' values using the median.
   - Dropped records with critical missing fields ('purchase_amount', 'category').
3. Business Insights Utilized Pandas aggregation to calculate total sales per category and average transaction value.
